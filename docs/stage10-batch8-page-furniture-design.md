## 1. 问题与类别（real-02 PDF，批次 6 后仍存的 15 条家具 heading）

- **A 页脚页码**："Page NN" ×12（物理页 2–13，显示号 = 物理页 − 1，封面不编号）
- **B 封面日期**：裸日期 ×1（页面中部 43.8%）
- **C 宣传语**：同一行 ×2（封面 + 末页，底带 95.2–97.2%，跨页逐字重复）

## 2. 结构信号实测（只读 shadow analysis，全 30 条 heading）

| 类别 | bot 百分比 | 跨页逐字重复 | 字号 |
|---|---|---|---|
| A 页码 ×12 | 恒 97.6% | 无（逐页文本不同，模板同形） | 8.0（全文档最小） |
| B 日期 ×1 | 45.7%（页中） | 无 | 16.0（=合法节标题） |
| C 宣传语 ×2 | 97.2% | 有（页 1+14 同带） | 17.0 |
| 合法节标题 ×12 | ≤ 83.2%（页首 7.7–9.6% 或页中 30–63%） | 无（全单页） | 16.0 |
| 表单残留 ×3 | 44.3–83.2% | 无 | 12.0 |

**信息管线审计**：`_classify_pdf_paragraph(text)` 纯文本接口——页号/
bbox/页高在调用点（`_parse_pdf` 循环）在手但未传入；跨页重复从未计算
（可文档级聚合）；字体/字号在 `extract_words` 调用处丢弃（未传
extra_attrs）。

## 3. 方案对比结论

- **局部无状态（纯文本）被否决**：文本形状 "Page \d+" 会误杀正文合法
  标题（排版规范类文档章节名 "Page 07"）；裸日期形状必误杀期间节标题
  （财报 "December 2025" 期间标题是合法高频形态）；宣传语无任何文本
  特征。Locale 泛化只能枚举，违反通用性。
- **文档级合取信号（推荐）**：
  - **D1**：bot ≥ 93% 底带 AND 文本 `^page\s*\d+$`（大小写不敏感）→ A 类
    （不依赖显示号==物理页数值匹配——real-02 实测存在封面偏移，数值
    匹配跨文档脆弱）
  - **D2**：bot ≥ 93% AND 规范化文本在 ≥2 页同一底带逐字出现 → C 类
  - 误伤反例逐条核验存活：页中 "Page 07"、页中裸日期、底缘 94% 单页
    合法标题、跨页重复页中标题（幻灯片同题）；v1 不做页首带
    （running head 与幻灯片同题标题结构同形 + 本文档合法节标题恰在
    页首带 → 证据窗不干净，列披露边界）
- **B 类日期划出范围**：位置/重复性/字号三类信号与合法期间标题完全
  同形，不存在低误伤通用信号 → 列已知限制（与 r59 ③ 家具划出批次 6
  同构的保守切分）。
- **字号信号不用**：需改 `extract_words` 生产调用且阈值文档相对化。

## 4. 架构门槛（r61 停链条款核验）

推荐**路 1：`_parse_pdf` 文档级后置过滤**——分类器与通用 heading 框架
零改动；元素收齐后对 heading 型元素以 locator 已有的 page/bbox + 页高
+ 一次性跨页重复聚合过 D1/D2，命中改 `paragraph` +
`metadata.heading_suppressed=page_furniture_*`。批次 6 全部文本单测
（含家具守护组）继续成立（它们测分类器，不测管线后置过滤）。
路 2（改 `_classify_pdf_paragraph` 签名引入位置/重复参数）= 接口改造，
按裁决不实施。

## 5. 拟议夹具矩阵（implementation batch，全合成零 real-02 逐字）

- F1 抑制：3 页底带页码行；2 页底带逐字重复宣传行；底带跨页重复裸日期
  （走 D2 重复证据）
- F2 存活：页中 "Page 07"；页中裸日期；底缘 94% 单页标题；跨页重复页中
  标题；页首带 running head（v1 边界锁定）
- F3 阈值：bot 93.0% 抑制 / 92.9% 存活；重复 ≥2 页才抑制
- F4 回归：批次 6 全部既有测试不变；端到端页中 "Page 21" 仍 heading；
  real-02 只读验收增量 30→16（家具 15→1，合法镜像 10/10，残留 3）
