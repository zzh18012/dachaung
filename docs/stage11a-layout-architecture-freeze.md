## Q1：raw words 是否长期一等输入？

**裁决：是。raw words 列（pdfplumber word dicts）为 PDF 布局
底座的长期一等输入；演进轴是"属性加富"，不是"载体替换"。**

依据：

1. **证据链已在其上闭合**——批次 11 shadow 原型只消费与生产同
   形态的 word dicts 即复现全部分区行为；批次 12 验收的核心
   不变量（词守恒 17/17 EXACT）以"词集合在分区前后不增不减
   不变形"为口径成立。底座换载体 = 该不变量口径作废。
2. **替代载体逐一排除**：
   - `page.chars` 直接消费：比 words 更低层，无词内分组，CJK
     场景 4-7 字符块重组成本转嫁给底座；chars 仅作**校准侧信道**
     （批次 11 §4 已识别：CJK 列河下限须从 char 级相邻间距推导，
     因 extract_words 的中文产出块状词使行内 gap 样本被列隙主导）。
   - pdfplumber 内置 layout 输出（extract_text layout 等非受控
     行为）：不可注入守卫判据，退化语义不受我们控制，排除。
   - OCR / 其他引擎：范围外（Stage 1 起排除）。
3. ** sanctioned 演进轴 = 属性加富**：(a) `extract_words(
   extra_attrs=[...])` 引入 font/size（批次 11 §6 实施前提 (a)，
   现状 :1076 未传）；(b) char 级间距校准数据作为 Tier-1 下限
   参数的推导输入（不进元素流）。两者均不改变"words 列 → 区域
   → 车道"的载体形状。

## Q2：区域/候选层放哪？

**裁决：两层分离——区域层 = 页内、ephemeral、车道前分区器
（已在产，冻结）；候选层 = 观察侧信道，零发射权（未实施，冻结
其位置契约）。不建文档级 layout 对象模型。**

1. **区域层（Tier-1，已在产）**：位置固定在词提取（:1076）与
   段落分组之间（`_page_paragraphs` :574）。区域是函数局部量，
   生命周期 = 单页处理；其持久痕迹只有两条——多栏页元素顺序
   （区左→区右，§1 修复本体）与区内正确 bbox。**区域不成为
   Element、不成为 schema 概念、不跨页持久化**。单区退化直通
   既有分组（:575-576）是结构性保证，不是配置。
2. **候选层（Tier-2，未实施）**：位置契约冻结为**并行观察车道**
   ——在区域形成后计算每区表格候选特征（批次 11 §2：行数 /
   大空档行数 / 空档词距比 / 左列 x0 稳定度 / 右列漂移 / 行高
   CV），输出仅供两个消费点：§3a 候选车道（须 ≥2 确认轴 +
   结构锚同时满足才可发射，且逐候选与既有 paragraph 去重替换
   ——**该替换点是唯一触及批次 10 停链语义的位置，单独裁决**
   ，本裁决不授权）与图注配对 region-id 门控（可选参数走
   Element.metadata 自由字典）。
3. **方案 B（共享 Layout Segmentation 重构）维持目标态参考**：
   重写 :346-421 核心分组 + 三车道消费端 + 发射顺序 = 全局
   table reconstruction framework，命中 r63 停链条件（批次 11
   §3 判定不变）。
4. **文档级对象模型明确不做**：跨页栏延续、文档级版式模板等
   若未来立项，须另裁；本裁决把底座钉在**页内**，防止 scope
   蠕变。

## Q3：五个保护面如何不被破坏？

| 保护面 | 机制 | 证据/护栏 |
|---|---|---|
| element 顺序 | 单栏页：单区退化直通，序列化零差异（结构性，非门控）；多栏页：区左→区右 = §1 修复本体，属有意修正且已在冻结基线内；Tier-2 候选零发射权，发射前不得交错进既有泳道 | 批次 12 验收：17 变化页全为物理多区页、单栏页零差异；六篇冻结基线（批次 13 §①）为漂移闸门 |
| locator | family 维持 page_geometry，形状零变化；region 身份只走 Element.metadata 自由字典，**永不进 source_locator** | 批次 20 契约（locator family 封闭四值）不被触碰；schema 0.6.0 零变化 |
| relation / 图注配对 | 现行匹配器（:109-151 同页 + 垂直距 + x 重叠贪心）零改动；region-id 门控 = 纯函数可选参数，实施须另批，以六篇冻结基线的 relation/caption 计数为守护 | 批次 13 冻结基线 + guard suites（99 passed 含批次 4/6/9/12） |
| caption 优先级 | 图注前缀集与分类（:51-73）零改动；Tier-2 候选若未来发射，结构锚的图注正则与分类同证据类（批次 11 §2） | 同上 |
| framed-table 行为 | `find_tables()` 泳道（:1107）零改动——Tier-1 不 crop、不消费表检测；Tier-2 候选车道与有框表 bbox 去重后才可进任何发射裁决 | 批次 12 Tier-1 验收有框表计数零变化 |

**验收仪器（任何 11-B 批次的强制门槛，本裁决冻结为标准套件）**：
词守恒（EXACT）+ 六篇冻结基线 diff（漂移必须逐页归因到本批
意图）+ guard suites + 全量回归全绿。

## Q4：回退路径？

**裁决：回退 = commit 级 revert + 基线重放，不设运行时开关。**

1. **commit 级**：每批实施落在 integration 分支，合并与否由
   验收裁决；偏差 → 分支废弃或 revert，main 只经已裁决分支
   FF 前进（搬运线纪律）。批次 12 Tier-1 即此模式：无 flag，
   回退 = revert aaff3df 中该块 + 回归重跑。
2. **不设运行时开关的理由**：flag 制造双生产行为，测试矩阵
   翻倍，且与"单一冻结基线"纪律冲突（基线必须回答"生产行为
   是什么"，而不是"两个可切换行为各自是什么"）。
3. **架构级回退**：Tier-1 的保守失败方向（错判 = 维持现状）
   使最坏情况 = 批次 12 之前语义；:575-576 单区退化路径就是
   关停点（一个调用点回退，prose 侧即恢复全页单区分组）。
   Tier-2 观察-only，关停 = 零变化。
4. **数据级参照**：outputs/batch12i_after（六篇 @aaff3df 解析
   JSON）+ 批次 13 冻结基线表 = 永久 pre-state 参照；任何
   11-B 批须证明其 diff 恰为本批意图集。
