## ① 为什么裸数字页码当时不能并入 D1（r62① 原始理由复现）

r62①（§147，2026-09-20）原文钉死 D1 = 底带 ≥0.93 ∧ heading ∧
`^page\s*\d+$`，"**不扩展到裸数字/日期/罗马数字/文件名等**
其他模式"。复现当时的排除理由：

1. **证据面空白**：real-02（当时唯一验收语料）的页码全部带
   "Page" 前缀（A 类 ×12），裸数字页码零实例——排除发生在
   无任何实例、无任何普查的背景下，是一事一批的范围冻结，
   不是逐类反例分析（批次 8 设计文档只分析了 "Page NN" 与
   裸日期两类）。
2. **信息面缺失（决定性）**：r62① 同段明示"本轮不引入字体/
   字号采集"。裸数字没有 "Page" 前缀的自证文本形态，在纯
   文本+位置信息面下，digit∧band 的误伤面（列表编号/图表
   数据号/章节号）**无法排除**——保守排除是当时信息面下的
   正确决策。
3. 裸日期的反例论证（"必误杀期间节标题"）被整句范围冻结
   外推到裸数字，但裸数字与裸日期的误伤面并不相同——这一
   点当时未区分。

**现评估**：信息面已变——Batch 14 词级 fontname/font_size
可用（r73 验收冻结），Batch 15/16 提供了当时缺失的全部三类
证据（下文②③④）。理由 2 已消解，理由 1 的证据缺口已补；
裸日期/罗马数字/文件名三项**维持冻结不动**（它们没有获得
任何新证据，本批只重开裸数字一项）。

## ② fontOut 是辅助还是必要条件

语料事实（探针 A/B/D 节）：

| 篇 | 底带数字 | fontOut | 序列拟合（显示=物理+常数偏移） |
|----|---------|---------|------------------------------|
| prod-01 | 33 | 33 (100%) | 33/33，偏移 −6（封面+前言偏移） |
| tech-03 | 233 | 233 (100%) | 233/233，偏移 0 |
| 其余四篇 | 0 | — | — |

- **作为必要条件的代价 = 0**：家族内 fontOut 100%（无漏）。
- **防护价值针对未观察负例**：已观察负例（tech-08 图内标签
  ×13、tech-03 页中数据数字 ×4）全部是正文族字体，但它们
  同时全部在带外——band 已独立防护。fontOut 的真实价值是
  对两类**语料零实例的开放风险**（无标点独立列表号 T3、
  底带非页码数字 T4）提供第二重防线，其中 T4（底带正文族
  数字）fontOut 是唯一区分信号。
- **稳健性量级支撑**：fontOut 依赖文档级 top-3 字体分布，
  页码族词数（466 量级）与正文词数（数万）差两个数量级，
  页码字体不可能进入 top-3——该合取不会因文档变长而退化。
- **建议（供裁决）**：fontOut 作**必要条件**（合取分量），
  理由 = 零漏代价 + T4 开放风险的唯一防线 + 符合 r74(4)
  "font 只能做组合证据"原则（本规则即组合形态）。诚实登记：
  仅当前语料 P1（digit∧band∧heading）已零 FP，fontOut/
  size 合取是对未来语料的保险，是否采纳为必要 = 裁决项。
- **禁止事项重申**：序列拟合（等差+常数偏移）仅作语义核证
  证据登记（本批用它证明 466/466 确为页码），**不进入谓词**
  ——r62① "不得要求显示页码==物理页码" 的精神对一切数值
  匹配成立，prod-01 偏移 −6 即是反例证明。

## ③ 五类负例的防护矩阵（r75(5)③ 必答）

| 负例类 | 语料实测 | 实测位置/字体 | 防护轴 |
|--------|---------|--------------|--------|
| 正文编号 | **零实例**（六篇无任何 digit-only paragraph 元素） | 假设风险 | digit-only 排除带标点形态（"1."/"1、"）；band+fontOut 防无标点独立列表号 |
| 图表编号 | tech-03 "图 N-N" ×227 带"图"前缀（非 digit-only）；纯数字数据标签 tech-08 ×13 + tech-03 ×4 | 全部页中、正文族字体 | band ∧ fontOut 双重防护 |
| 列表编号 | **零实例**（形态上多为 digit+标点或行内） | 假设风险 | 同正文编号行 |
| 章节数字标题 | tech-08 Impact '5' ×6（bot=0.72 中上部，r=60.76 超大） | 非底带 + 超大字号 | band ∧ size-cap（P3 的 r≤1.2 恰为此类设） |
| 页中数字标题 | tech-03 p25/p32/p160 ×4（数据数字，bot 0.19~0.66） | 页中、正文族 | band 防护 |

**关键结论**：五类负例中三类的防护主轴是 band（与 D1/D2
同轴）；fontOut 与 size-cap 是纵深（针对章节数字若落入底带、
底带非页码数字两个假设类）。当前语料上 P1 已零 FP，P3
（digit∧band∧heading∧fontOut∧r≤1.2）对全部已观察 + 假设
负例类均零命中。

## ④ false positive taxonomy（登记）

- **T1 图内/图表数据数字**（实测 17 条：tech-08×13 + tech-03×4）：
  页中 + 正文族 → band ∧ fontOut 双防护。
- **T2 章节装饰数字**（实测 tech-08 Impact ×6）：非底带 +
  超大字号 → band ∧ size-cap 防护；若此类落入底带（语料未
  观察），fontOut 无防护力（Impact 本身圈外），size-cap 是
  唯一防线。
- **T3 列表/正文独立编号**（零实例）：形态（标点）+ 类型
  （paragraph）+ band + fontOut 四层；残余风险 = 底带无标点
  独立编号——未观察。
- **T4 底带非页码数字**（零实例）：**真正的开放风险类**（底
  脚注号、底栏统计数）。fontOut + size-cap 部分防护；若与
  页码同形同字体则不可分。这是本设计必须保留"候选抑制可
  回滚 + reason code 独立"的原因，也是不允许单规则自动化
  的原因。
- **T5 页中数字标题**（实测 4 条）：band 防护。

## ⑥ 与现有 D1/D2 的关系

- **D1 保持冻结**（`^page\s*\d+$` 文本形态不变）；**D2 不受
  影响**（页码文本逐页互异，与同文重复正交）。裸数字家族
  建议立**独立规则 D3**（reason code
  `page_furniture_digit_page_number`），不扩 D1 正则——理由：
  (a) D1 是纯文本形态规则，D3 是 digit∧band∧font∧size 组合
  证据规则，语义不同源；(b) 独立 reason code = 独立计数/
  审计/单点回滚；(c) r62① 其余排除（日期/罗马数字/文件名）
  冻结面零扰动，重开切口最小。
- **架构意义（须显式裁决）**：D3 若实施，将是**第一个消费
  词级 font 属性的生产规则**——Batch 14 采集（零消费冻结）、
  Batch 15/16 证据、D3 = Tier-2 第一消费点。消费位置在
  `_suppress_page_furniture_headings` 文档级后置过滤内（band
  聚合状态与 font 通道同点），不触碰 `_classify_pdf_paragraph`
  （r74(5) 禁令维持）。
- **新的文档级状态依赖**：fontOut 依赖全文档 top-3 字体分布
  ——furniture 判定首次依赖字体统计。top-3 是 Batch 15 观察
  面定义，转生产需单独钉死参数与退化行为（无 chars 属性词
  → 不得命中 D3，保守存活）。

## ⑦ furniture taxonomy 是否需要重新定义

**不需要重构，是增列**。现有 suppression taxonomy 仍是
"位置带 × 证据轴"结构：带（底带 0.93，r62④ 冻结）不变；
证据轴从 {文本形态（D1）, 跨页同文重复（D2）} 增列
{digit 形态 ∧ fontOut ∧ size-cap（D3）}。日期/罗马数字/
文件名维持排除。taxonomy 的语义边界（"页面家具"= 文档级
重复性装饰结构）不受影响——页码本就是家具定义的典型成员，
D1 已含 "Page N" 形态，D3 只是同一语义家族的裸数字形态补全。

## 设计轮结论

1. r62① 排除裸数字的原始理由（信息面缺失 + 零实例下的范围
   冻结）已被 Batch 14/15/16 的证据消解；仅裸数字一项具备
   重开条件，日期/罗马数字/文件名维持冻结。
2. 语料证据：466/466 底带裸数字 = 页码（序列拟合 100%）∧
   fontOut 100% ∧ 五类负例零落带。P1 已零 FP；建议 D3 =
   P3（digit∧band∧heading∧fontOut∧r≤1.2）以覆盖 T2/T4 假设
   风险类。
3. 本批零实现：不实施 D3、不扩 D1、不建 font 消费通道。
   实施与否、fontOut/size 合取是否采纳为必要条件、top-3
   参数钉死，全部留待裁决。
