## 1. 病灶的共同根因（管线图，fallback_parser.py）

| 层 | 位置 | 事实 |
|---|---|---|
| 词提取 | :849 | `extract_words` 全页一次；无 font/size（`extra_attrs` 未传；`page.chars` 有但从未消费） |
| 行分组 | :346-403 | 全页 y 中心聚类 ±3.0pt——**跨栏同 y 词合并成"行"** |
| 段分组 | :389-421 | 行距 >1.5×全页中位词高即切；行结构死亡，union bbox |
| 分类 | :455-471 | 纯文本（bbox/字体在调用点可用但未传入） |
| 表检测 | :880 | `find_tables()` 默认 lines 策略——**无线框盲区** |
| 图注配对 | :108-151/:269-314 | 同页 + 垂直距 ≤50pt + x 区间重叠>0 + **全页贪心**——无栏身份 |
| 发射 | :827-1075 | 页内固定泳道（全段→全表→全栅格图→全矢量图）；element_id 追加即编号 |

**根因**：全代码库不存在任何区域/分栏概念（grep 栏/column/region/zone
仅命中跨页表格的 x 边缘聚类 :602-617 与上下 y 带 :598-599/:762）。
§1（行分组跨栏合并 + 配对无栏身份）与 §3a（列结构死于段落通路 +
检测器盲区）是**同一缺失的两个症状**。批次 10 已证：在 word-几何
单一信息面上用阈值补表格（P1 漏报与 N3/N4 误报并存）不可行。

## 2. 架构方案 A：保守区域底座（Region Substrate Pre-Partitioner）

**两级结构，发射解耦**：

- **Tier-1 保守区域形成（影响 prose 发射）**：在 :849 与 :859 之间
  插入纯函数分区器——投影剖面"全高空白河"（某 x 带在全页所有词上
  均为空白）递归切分；**数据驱动河宽下限** = max(15pt, 2.5×区域
  行内相邻词距中位数)；**行级支持判据**：双岸行自身空档须 ≥
  max(下限, 2×该行中位字高)（大字号通栏标题拒绝开口）；**质量守卫**：
  两侧各须 ≥2% 字符质量（裸编号列不成区）。每区独立调用现有
  `_group_words_to_paragraphs`（纯函数、零全局态，可安全重入），
  段落按"区左→区右"进入现有段落泳道。
- **Tier-2 候选区（零发射影响）**：区内表格候选特征（行数、大空档
  行数、空档/词距比、左列 x0 稳定度、右列 x0 漂移、行高 CV）仅供
  F-A 候选车道与配对门控消费；图注配对器加可选 region-id 门控
  （走 Element.metadata 自由字典，**不动 source_locator/schema**）。

**关键架构洞察（同构冲突的消解）**：N4 双栏正文不再是"表格误报"，
而是 Tier-1 的**正确输出**（两栏各自成区，区内无表格特征）——§1
修复与 §3a 误报消除是同一机制。N3 编号列表被三重保守机制挡在区外
（校准下限 / 行级支持 / 质量守卫）。真正的表格性判定只发生在
Tier-2，且不再与"是否分栏"耦合。

## 3. 架构方案 B：共享 Layout Segmentation 重构

把 `_group_words_to_paragraphs` 重构为共享分割阶段，产出类型化
segment（段落流/栏结构/表格候选），段落、表格、图注三车道共同消费。
- 优点：单一真相源，表注配对天然带区域身份；候选与发射同源。
- 代价：改写 :346-421 核心分组 + 三车道消费端 + 发射顺序 = **全局
  table reconstruction framework**，且元素顺序/element_id 大面积
  变化 → 命中 r63 停链条件（大幅重构 PDF grouping）。
- 判定：B 作为目标态架构记录，**不作为本轮实施候选**。

## 4. Shadow 原型证据（v0→v1 迭代，全部可复现）

**v0 教训**（绝对 15pt 阈值）：词距本身宽的散文被误分 4 区；同字号
伪标题割穿双栏。→ v1 改数据驱动下限 + 行级支持判据。

**v1 夹具矩阵 8/8 按设计**：单栏 1 区；宽词距压力 1 区（校准证明）；
N4 双栏 2 区；大字号通栏标题 1 区（占用阻塞）；N3 现实/纯编号 1 区；
F-A KV 与稀疏真表 1 区 + 候选轴起火（max_gap 216/210pt、ratio 2.4/1.0、
右列漂移 56pt/0）。

**真实语料**：
- real-04（§1 本尊）p002 → 精确 2 区 [56.6-283.4]/[311.9-538.8] ✓
- acad-03 p002 → 2 区 [53.5-295.6]/[317.6-560.7] ✓
- 退化性：real-02 3/3、prod-01 7/7、tech-08 8/8、tech-03 10/10
  采样页全 1 区（单栏页零输出变化）

**诚实发现的两个校准缺口**（v1 的保守失败 = 维持现状，无回归）：
1. **CJK 稀疏词距**：中文 extract_words 产出 4-7 字符块，行内间隙
   样本被列间隙本身主导（tech-08 p12 gap_median=18.5pt → 下限 46pt
   > 实际列河 35pt → 不分裂）。修复方向：下限从 `page.chars` 级
   相邻字符间距推导（CJK 字内距 ~0-1pt），与 font/size 引入
   （extra_attrs）同一信息面升级。
2. **窄槽学术版式**：acad-03 p004 槽仅 11pt < 15pt 地板 → 保守
   不分裂。修复方向：下限叠加字高相对项（如 1.5×中位字高）；
   风险是与两端对齐文本的 1-2×字高词距混淆，需夹具矩阵扩充
   后再裁。

## 5. 影响面对照

| 影响面 | 方案 A（Tier-1+Tier-2） | 方案 B |
|---|---|---|
| 元素顺序 | 单栏页零变化（退化保证）；多栏页有意修正（区左→区右，取代今日交错文本） | 全量重排 |
| element_id | 单栏页不变；多栏页变化（今日该页 id 本就建立在错误文本上） | 大面积变化 |
| locator | 形状零变化（page_geometry）；多栏页 bbox 由全宽 union 变为区内正确 bbox | 零变化 |
| relation/图注配对 | 可选 region-id 门控（metadata 通道，schema 零变化） | 同源门控 |
| table merge（跨页） | 鲁棒（内部重排序 :726-728），零改动 | 需重验 |
| 既有有框表格 | find_tables() 泳道零改动（方案 A 不 crop） | 重构消费端 |
| caption | 匹配器纯函数加可选参数，零 schema | 同 |
| schema/统一模型 | **零变化** | 零变化 |
| chunker | 消费列表顺序，无需改动 | 无需改动 |
| 回归面 | 多栏页行为变化 = §1 修复本体，需门控发布 + 现有 5617 测试 + 真实语料 diff 护栏 | 全量 |

## 6. 结论与 r66 请求

1. **可行性结论**：受控区域级 substrate **在架构上成立**——方案 A
   以纯函数插入、零 schema 变化、单栏退化保证、保守失败方向
   （错判=维持现状）满足 r64 "不推翻现有解析器"约束；批次 10 的
   停链条件（全局 framework、schema 变化、与 §1 耦合的独立表格
   重建）在方案 A 下不成立——§1 与 §3a 被**同一机制**解决而非
   两处耦合改造。
2. **实施前提**（若授权，另行批次）：(a) font/size 进词层
   （extra_attrs）；(b) CJK char 级下限校准；(c) 夹具矩阵扩充
   （窄槽、CJK 双栏、跨页栏）；(d) 多栏页 diff 护栏与门控发布；
   (e) Tier-2 F-A 候选车道仅在 ≥2 确认轴 + 结构锚（图注正则，
   与分类 :455 同证据类）同时满足时发射，且逐候选与既有
   paragraph 元素去重替换——该替换是唯一触及批次 10 停链语义
   的点，需单独裁决。
3. 若 Sol 权衡认为多栏页行为变化仍属高风险重排，本设计亦支持以
   "不可安全局部实现"收口——方案 A 的证据（真实语料精确分裂 +
   零单栏回归）为该裁决提供量化基础。
