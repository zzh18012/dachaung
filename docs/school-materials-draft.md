## 1. 成果简介（可直接用作"项目总结/摘要"）

本项目面向 KVFS 复合文档存取需求，研制了 PDF/DOCX 复合文档的确定性解析
与结构-语义分块原型系统。系统将复合文档转换为统一文档模型（元素/分块/
关系三层 JSON，带逐元素源定位），经结构分块（标题硬边界、表格独立、
长度受控）与 JSON Schema 强制校验后输出可追溯的结构化数据，全过程
**无 OCR、无概率匹配、无学习式版面模型**。

在 24 篇核心语料的分层评测体系上：comparison 门四指标 unit_alignment
0.8297 / extraction_coverage 0.7635 / nontext_detection 0.7004 /
boundary_error_rate 0.7378，24/24 通过 Schema 校验；分块对齐指数（ARI）
0.3345（1200 字符宏观口径），显著优于两冻结基线（0.2658 / 0.2621），
达粒度理论上界（oracle 0.4159）的 80.43%；关系抽取（单文档定点锚评测）
精确率 1.0 / 召回率 0.35 / F1 0.5185。系统通过终测复现验证：执行前六要素
冻结，136 个稳定字段与冻结基线**逐项精确相等**（REPRODUCED_IDENTICAL）。

项目交付：解析管线与 CLI 工具链、统一文档 Schema（0.6.0）、评测框架、
容器化交付与 CI 链、结题报告与证据包、演示页。

## 2. 技术路线

1. **确定性解析**：默认 fallback 解析器（pdfplumber + python-docx）只使用
   几何与结构事实（PDF 字符/线框几何、DOCX 段落/表格样式）；kreuzberg
   保留为可选路径。解析器注册表支持能力快照、扩展名发现、选择解释、
   竞争审计、身份与来源追溯，外部插件显式加载。
2. **统一文档模型**：schema 0.6.0 三层结构——元素（类型/内容/父级/
   源定位/置信度）、分块（文本 + 非空元素溯源链）、关系（锚定关系带
   证据）；源定位四族封闭（页几何/结构索引/行地址/容器行），PDF 与
   DOCX 各有稳定定位；顶层 SHA-256 支持去重与追溯。
3. **结构分块**：标题硬边界、表格独立成块、max_chars=800 词界切分；
   "不丢不重"由统一规范化文本拼接比较测试守护。
4. **关系抽取**：817 个硬边界派生锚点 + 序数回退，确定性规则链。
5. **质量门**：写盘前 JSON Schema 强制校验，失败不产生半成品。
6. **评测与复现**：三层评测（结构化运行/指标计算/关系抽查）+ comparison
   回归门（核心指标相对劣化 >5% 判回归）+ 六要素冻结终测。

## 3. 创新点

1. **确定性约束优先**：以"同输入 + 同依赖 ⇒ 逐字节稳定输出"为系统级
   承诺，并以 136 稳定字段终测实证——区别于常见概率式文档理解方案，
   结果可审计、可复现、可追责。
2. **统一文档模型 + 全链溯源**：每个分块可回溯到具体源元素（非空
   source_element_ids 强制），每个元素带源定位，为下游 KVFS 存取提供
   结构化锚点。
3. **分层评测体系与回归门**：24 篇三 split（dev/comparison/holdout）
   语料 + 13 项自动指标 + 关系定点抽查 + 基线链管理（r5→r6→r7 冻结），
   评测纪律（protected split 授权读取、比例指标分母为零返回 null 而非
   满分）保障数字可信。
4. **结构性差距分析方法**：以冻结金标上的 oracle 上界（0.4159）量化
   "目标不可达部分"，将 ARI 未达标归因到粒度错配（约 75% 差距为结构
   不可达），而非笼统归咎于实现质量。

## 5. 未完成目标与原因

1. **ARI 0.75 目标未达**（实际 0.3345）：经冻结金标 oracle 分析，上界
   仅 0.4159——约 75% 差距属分块粒度与金标粒度的结构不可达；系统已
   达上界八成并显著超基线。诚实的结论是：在当前金标粒度定义下该目标
   数字不可达，差距已定位到结构约束而非实现缺陷。
2. **关系召回偏低**（R = 0.35）：确定性规则链只在高置信锚出手（P = 1.0
   的代价）；且评测范围为单文档定点锚抽查（acad-03 / 20 金标边），
   不外推全语料。
3. **24 篇核心语料关系锚绑定未执行**（NOT_EXECUTED / DEFERRED_POST_FINAL）：
   结题前关系工程已按裁决关闭，作为后续工作披露。
4. **holdout 口径限制**：标注时已知锚分布（INFORMATIONAL /
   WITH_KNOWN_ANCHOR_EXPOSURE），不能宣称严格盲测。
5. **扫描件 PDF 不支持**：确定性约束下不引入 OCR，列为范围边界。
